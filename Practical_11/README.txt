Practical 11 - StudentHub
Student Management CRUD with Search and Filter

Features Implemented:
1. Complete CRUD operations on students table:
   - Create: add_student.php
   - Read: students.php
   - Update: edit_student.php
   - Delete: delete_student.php (Soft delete setting status to inactive)
2. Dynamic search by name, email, and mobile number.
3. Multi-field filtering by Course and Year.
4. Intermediate extension: Export complete student directory to CSV (export_csv.php).
5. Minimum 20 seeded student records provided in schema.sql.

How to Run:
1. Import schema.sql into studenthub_db.
2. Open http://localhost/Practical_11/students.php
