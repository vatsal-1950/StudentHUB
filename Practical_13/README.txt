Practical 13 - StudentHub
PHP JSON API and AJAX/Fetch-Based CRUD without Page Reload

Features Implemented:
1. RESTful PHP JSON API endpoint (api.php) with proper HTTP status codes (200, 201, 400, 500).
2. Asynchronous CRUD operations using JavaScript Fetch API without full page reload.
3. Debounced real-time live search across student records.
4. Asynchronous Add, Edit and Delete with instant DOM updates and toast feedback messages.

How to Run:
1. Ensure MySQL is running and schema.sql is imported.
2. Open http://localhost/Practical_13/ajax_crud.php
