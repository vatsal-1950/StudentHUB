Practical 7 - StudentHub
PHP Form Processing with Server-Side Validation and CSV/JSON File Storage

Features Implemented:
1. Student registration form submitted using POST method.
2. Server-side validation for name, email, mobile, course, year, gender, password and terms.
3. Server-side sanitization using trim() and htmlspecialchars().
4. Safe file writing to both CSV (students.csv) and JSON (students.json).
5. Contact and feedback form processing with CSV and JSON storage (contact.csv, contact.json).
6. Success and error response banners displayed dynamically.
7. Intermediate extension: Web page (view_records.php) displaying stored records in structured HTML tables.
8. Retains full navigation across all StudentHub portal pages (Home, About, Register, Login, Dashboard, Events, Profile, Contact, FAQ, Feedback, Records).

How to Run:
1. Open XAMPP Control Panel and start Apache.
2. Place or link Practical_7 into C:\xampp\htdocs\
3. Open browser and visit:
   http://localhost/Practical_7/index.php
   or
   http://localhost/Practical_7/register.php
