Frequently Asked Questions


+ How does Practical 7 handle registration?

Registration is processed by PHP on the server side with validation, sanitization, and storage in CSV and JSON formats.

+ Where can I see stored records?

Click on the Records menu item or visit view_records.php to inspect all records from CSV and JSON storage.

+ How do I send a contact message?

Go to the Contact page, fill in your name, email and message, and submit via POST to contact.php.

+ Can I run this without XAMPP?

PHP processing requires a PHP server such as XAMPP Apache or the built-in PHP development server.
